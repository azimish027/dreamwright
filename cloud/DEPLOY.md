# 云端同步接入指南（v4 · 适配新一代 CloudBase「PostgreSQL / Supabase 版」）

> 目标：把「IP 创作工作台」接上腾讯云开发，实现电脑 / 手机 / 平板多端自动同步。
> 完成后只需要把**两个值**填进工作台右上角「登录 / 注册 → 云端配置」：
> **云函数访问地址** + **访问密钥**。
>
> 前置：一个能上微信的账号（扫码登录腾讯云用）。**不需要会编程。**

---

## ⚠️ 新版环境跟旧教程不一样，先看这段（很重要）

2026 年 8 月起，腾讯云开发新环境用的是 **PostgreSQL（SQL 型）**（也叫「CloudBase for Supabase 版」）。
它跟旧版有两点大不同，**这正是之前卡住你的原因**：

1. **云函数连数据库不再需要 host / 端口 / 用户名 / 密码** —— 旧教程让你去抄的「数据库连接信息」在新平台里**没有那个入口了**。新平台改用**平台自动签发的一把 API Key**，你根本不用找连接信息。
2. 数据表**不用**在控制台里点来点去建，改为在 **SQL 编辑器里粘贴一段脚本执行一次**（本目录 `cloud/ipstudio/init.sql`），比旧方式更简单。

> 工作台是**原生 HTML 单文件**，不依赖任何框架。控制台里凡是让你「选框架 / 选模板（React/Vue/Node）创建应用」的页面，全部退出不用。

---

## 第 1 步：进入你的环境控制台

1. 打开 👉 **https://tcb.cloud.tencent.com**（微信扫码登录）。
2. 点进你的**环境**（写着环境 ID，形如 `xxx-1a2b3c`）。
3. 确认左侧菜单有 **「云函数」** 和 **「数据库」**。有就对了，继续。

---

## 第 2 步：执行一次建表脚本（约 2 分钟）

1. 左侧菜单 →「**数据库**」（可能叫「数据库 / PostgreSQL / 数据管理」）。
2. 找一个 **「SQL 编辑器」**（也可能叫「新建查询 / SQL 查询 / 数据库管理(DMC)」），点开。
3. 打开本目录文件 **`cloud/ipstudio/init.sql`**，把里面【从 `CREATE TABLE` 到最后的 `$$;`】全部内容**复制 → 粘贴**进 SQL 编辑框。
4. 点「**运行 / 执行**」。看到「执行成功 / SUCCESS」就完成了。
   - 脚本很安全：建 3 张空表 + 1 个函数，**可以重复执行**，不会出错。
   - 不需要手动建表、不需要填字段、空表是正常的。

> 这一步做一次就永远不用再做了。以后工作台加新功能，数据都存在同一张 `ip_recs` 表里。

---

## 第 3 步：给云函数配 3 个环境变量（约 3 分钟）

1. 左侧菜单 →「**云函数**」→ 点进你建的 **ipstudio** 函数。
2. 找「**函数配置 / 配置**」→「**环境变量**」，添加 **3 个**：

| 变量名 | 填什么 |
|---|---|
| `ENV_ID` | 你的**环境 ID**（页面顶部或「概览」页有，形如 `xxx-1a2b3c`） |
| `API_KEY` | 控制台里那把 **API Key**（一整串字符，见下面"API Key 从哪拿"） |
| `ACCESS_KEY` | **你自己编一串**，比如 `ipw2-我的工作台-9527`（这个要填进工作台） |

3. 保存。**如果之前函数是用旧 zip（pg 版）上传的，需要重新上传一次 `cloud/ipstudio.zip`**：
   函数详情页找「**更新代码 / 上传代码 / 部署**」→ 选 **ipstudio.zip**（本目录已打好，4KB，零依赖，**不会问你要不要装依赖**）→ 部署。

### API Key 从哪拿？

新平台在创建环境时自动生成了一组密钥，去控制台找 **「API Key / API Keys / 密钥管理 / 身份认证」** 页面（也可能在环境首页右下角），里面通常有两把：

- **service_role / API Key**（服务端专用，要的是这把，长的、开头像 `sb_secret_...` 或一长串）
- anon / Publishable Key（前端用，不是这把）

把 **service_role 那把**整串复制进 `API_KEY`。

> 如果整个控制台都找不到「API Key」字样：**截图发我**，不同版本放的位置不一样，我按你的界面圈。

## 第 4 步：给云函数开 HTTP 访问路径（约 2 分钟）

> ### 🎯 先回答你最担心的问题：要不要买域名？
>
> **不用买！不用备案！不用花一分钱。**
> 你看到的「自定义域名要钱 / 要备案」是在问你要不要绑一个**自己的品牌网址**（如 `www.我的小说.com`）——那是给对外运营用的**可选升级项，跟我们无关，跳过它**。
>
> 你的环境**免费自带一个默认域名**（形如 `xxx-1a2b3c.ap-shanghai.app.tcloudbase.com`），云函数挂到它下面就能被工作台调用。官方限制只影响「浏览器打开网页」的场景；我们这种**程序后台传数据的接口调用不受影响**，个人用完全没问题。

1. 左侧菜单 →「**HTTP 网关**」（旧版叫「HTTP 访问服务 / 访问服务」，找不到就搜索框搜「HTTP」）。
2. 找到「**域名关联资源 / 路由管理**」→ 点「**新建 / 添加路由**」。
3. 按这样填（**域名那格千万不要去点「自定义域名」**）：
   - 关联资源类型：**云函数**
   - 资源对象：选你建的 **ipstudio**
   - 域名：**选「默认域名」**（是下拉里现成的一项，不是让你填网址；有的版本还能选 `*` 匹配所有域名，选 `*` 也行）
   - 触发路径：填 `/api`（或 `/`）
   - 鉴权：公开访问 / 无需鉴权（不怕，代码里 ACCESS_KEY 已挡一层）
4. 保存后，页面会显示一条**访问地址（URL）**，形如：
   `https://xxx-1a2b3c.ap-shanghai.app.tcloudbase.com/api`
   把**整条 URL 复制**下来 —— 这是要填进工作台的「云函数访问地址」。
5. 如果云函数详情页里也能看到「HTTP 访问 / 触发方式」模块 → 那里同样操作：新增访问路径，域名选**默认域名**，路径 `/api`。

> ⚠️ 千万别点任何「添加自定义域名 / 绑定域名 / 域名备案」——那是收费路径，我们不走。
> 若「域名」下拉里**看不到**「默认域名」选项：截图发我，我按你的实际界面告诉你该点哪。

---

## 第 5 步：填进工作台，注册账号（约 2 分钟）

1. 打开工作台 → 右上角「登录 / 注册」。
2. 弹窗底部「云端配置」填**两个值**：
   - 云函数访问地址：第 4 步复制的那整条 URL
   - 访问密钥：第 3 步你自己编的 `ACCESS_KEY`
3. 用户名 + 密码注册一个账号（注册即登录，首次自动把本地数据整库上传）。
4. 右上角状态变「✓ 已同步 · 云」即成功。

---

## 第 6 步：第二台设备（电脑 / 手机 / 三星平板）

1. 另一台设备打开**同一份工作台文件**（把 `IP创作工作台-正式版.html` 传过去直接打开，或以后用静态托管拿固定网址）。
   - 静态托管 = 把工作台 HTML 变成网址：环境左侧「静态网站托管」上传文件后，用**免费的默认域名**（形如 `xxx.tcloudbaseapp.com`）访问即可，**同样不用买域名**。只是首次打开浏览器会弹一个「继续访问」提示页，点一下「继续访问」就好——个人使用无碍。
2. 右上角登录**同一账号** → 自动拉取 → 数据一致。
3. 任一端改动，另一端等几秒或点右上角状态圈即可同步。

## 没接云之前 / 出问题时

- 不填任何云端配置 = **演示模式**：账号数据只存本机，但能完整走一遍「注册 → 登出 → 换账号」流程。适合先体验再上云。
- 云函数调用报错时，返回的中文提示会直接告诉你问题（密钥不对 / 数据库没初始化 / 会话失效等）。
- **任何一步卡住**：截图 + 报错文字发我，我按你控制台的实际界面告诉你点哪里。

### 常见报错对照

| 工作台/云函数提示 | 原因 | 解决 |
|---|---|---|
| `HTTP 401 / 网关拒绝访问` | HTTP 网关那条路由的「鉴权」还开着「需要鉴权」，请求被网关拦下、没到云函数 | 控制台 → HTTP 网关 → 编辑 /api 路由 → 鉴权改成「公开访问 / 无需鉴权」 |
| `密钥不对…` | ACCESS_KEY 前后端不一致 | 云函数环境变量与工作台「访问密钥」填同一串 |
| `数据库还没准备好…` | 还没执行 init.sql | 做第 2 步，然后重新注册或再点一次同步 |
| `API_KEY 不对…` | 抄的 Key 不对/有多余空格 | 重新从控制台复制 service_role Key |
| `会话失效，请重新登录` | 登录超 30 天或换设备 | 重新登录一次 |
| 点同步没反应 | HTTP 访问路径没配/地址填错 | 核对第 4 步的整条 URL |
