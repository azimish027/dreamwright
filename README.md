# 筑梦之境 · Dreamwright

一个跑在浏览器里的**个人 IP 创作工作台**——单文件 HTML，双击即用，数据全在本机。

日系 galgame 视觉语汇：标题画面、对话窗看板娘、选项肢弹窗、章节过场、存档槽、控制条。

## 功能一览

- **企划树**：多 IP / 多企划管理，世界观、人物、大纲分支树
- **文稿**：章节卷章编辑、草稿纸手写、标记与逻辑线
- **灵感 / 模板 / 资产库**：灵感捕捉、可复用模板、立绘设定资产管理
- **统计**：打卡热力、字数、周历
- **AI 顾问「梦梦」**：检索你的作品后回答（带引用跳转）、逻辑体检（未回收伏笔 / 零出场人物 / 断头逻辑线…）
- **数据**：存档槽快照、备份导出 / 导入、可选云同步（自配 CloudBase）

## 快速开始

1. 下载 `dist/IP创作工作台-开源版.html`，双击用浏览器打开（推荐 Chrome / Edge）
2. 数据自动存在浏览器 localStorage，可随时在「数据」页导出备份文件
3. 想用 AI：顶栏「AI」→ 设置，填任意 OpenAI 兼容接口（DeepSeek / Kimi / 混元 / 腾讯云开发 CloudBase AI 均可），密钥只存本机

> 注意：AI 接口需要通过 http(s) 访问页面才能调用（浏览器对 file:// 有跨域限制）。本地起个静态服务即可，例如 `python -m http.server`。

## 自行构建

```bash
cd src
node build.js          # 标准构建 -> ../IP创作工作台-正式版.html
node build.js --public # 开源构建 -> dist/IP创作工作台-开源版.html（不含任何个人配置）
```

可选：把你的 AI 配置写进 `tools/myai.local.json`（已被 .gitignore 排除），`node build.js` 会自动注入：

```json
{ "baseURL": "https://…/v1", "key": "你的Key", "model": "模型名" }
```

## 启用真实云端（CloudBase · v14.1）

从 v14.1 起，「账户」弹窗支持**直连腾讯云开发 CloudBase**：匿名一键登录、企划/条目/页面/标记/打卡等数据多端云同步、AI 每日额度由服务端统一管理（匿名 20 次 / 天）。无需自建云函数、无需备案。

### 1. 云开发控制台（一次性）

1. 打开 [云开发 CloudBase 控制台](https://console.cloud.tencent.com/tcb)，新建环境（或选已有环境），记下**环境 ID**（形如 `xxx-abc123`）。
2. **登录授权 → 登录方式**：开启「匿名登录」。
3. **数据库 → 新建集合**两个：
   - `ipstudio_data`（业务数据，字段含 `_cat _rid _uid _deleted _ts`）
   - `ipstudio_quota`（AI 额度计数，字段含 `_uid date count`）
4. 分别给两个集合设置**安全规则**（保证只有本人能读写自己的数据）：
   ```json
   { "read": "auth.uid == doc._uid", "write": "auth.uid == doc._uid" }
   ```

### 2. 应用内连接

- 构建时若 `tools/myai.local.json` 里写了 `cloudEnv`，打开即自动连该环境；
- 否则在「账户」弹窗的 **CloudBase 云端** 区填入环境 ID，点「连接云端」即可。
- 点「✦ 一键匿名体验」：浏览器向 CloudBase 发起匿名登录，之后所有改动会自动同步到云端，换设备用同一账号打开即续上。

> AI 额度：未登录为 0；匿名 / 登录用户每日 20 次（服务端计数，跨设备共享同一上限）。无备案也能用——这是个人云账号应用，不是面向公众的社区广场（公开社区 / 评论 / 连载需 ICP 备案与内容审核，属合规范畴，非代码限制）。

## 技术要点

- 零依赖、零框架：原生 JS + 单文件构建脚本，所有资源（字体 / 立绘 / 图标）base64 内嵌
- 全部数据本地存储，**没有任何遥测**；云同步为可选功能，需自行配置自己的 CloudBase 环境
- 字体：思源黑体（正文）、梦梦可爱体 / 奶泡体 / 像素体（标题）、栗山巧緻（正文可切换）
